JavaScript Concepts

5 konsep dasar JavaScript

01/05

querySelector

digunakan untuk mencari dan mengambil elemen HTML tertentu berdasarkan selector yang diberikan, seperti tag, class, atau id. Dengan querySelector, JavaScript dapat menemukan elemen tersebut sehingga kita bisa membaca, mengubah, atau memanipulasinya menggunakan kode JavaScript.

02/05

addEventListener

digunakan untuk mendeteksi suatu kejadian atau event yang terjadi pada elemen HTML, seperti klik, mengetik, atau scroll. Setelah event tersebut terjadi, JavaScript dapat menjalankan fungsi tertentu sebagai respons terhadap event tersebut.

03/05

classList

digunakan untuk menambahkan, menghapus, atau mengubah class pada elemen HTML sehingga tampilan atau perilaku elemen dapat diubah melalui CSS.

04/05

scrollIntoView

digunakan untuk menggeser tampilan halaman menuju elemen HTML tertentu. Metode ini dapat digunakan untuk membuat perpindahan menuju suatu bagian menjadi lebih mudah.

05/05

textContent

digunakan untuk membaca atau mengubah teks yang terdapat di dalam suatu elemen HTML. Dengan textContent, JavaScript dapat mengambil teks dari elemen atau menggantinya dengan teks baru secara langsung.
