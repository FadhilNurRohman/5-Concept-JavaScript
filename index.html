01/05

querySelector

digunakan untuk menghubungkan kode JavaScript dengan elemen HTML agar elemen tersebut bisa dimanipulasi secara dinamis. Ibaratnya, jika HTML adalah tubuh dan JavaScript adalah otaknya, maka querySelector adalah tangan yang digunakan otak untuk memegang atau mengubah bagian tubuh tertentu.
